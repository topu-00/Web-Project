# Waste Management System

A web-based Waste Management System designed to provide a simple and user-friendly interface for managing and promoting proper waste disposal.

## Technologies

* HTML5
* CSS3
* JavaScript

## Features

* User-friendly web interface
* Waste management related information
* Clean and organized layout
* Interactive elements using JavaScript
* Responsive web design
* Easy navigation between sections

## Project Structure

* `HTML` — Provides the structure of the website
* `CSS` — Handles the design, styling, and layout
* `JavaScript` — Adds interactivity and functionality

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Explore the Waste Management System.
